# SILKFRONT — Комплект графических ассетов интерфейса (UI Asset Pack)

Графический набор ассетов для перерисовки интерфейса игры **SILKFRONT**, вдохновленный:
1. **Warcraft III** (тяжелый резной камень, кованое железо, золотые фаски кнопок, монументальный нижний пульт, рамка миникарты, стилизованные шкалы здоровья, 3x3 сетка приказов с горячими клавишами).
2. **Концептом «Древней Колонии» (Фото 2)** (темная готика, органическая паутина, теплое янтарное биолюминесцентное свечение, ресурсы: *Шёлк, Пища/Мясо, Кристаллы*, здания пауков: *Главное гнездо, Инкубатор, Шелковая мастерская, Паутинная башня, Паутинное заграждение*).

---

## Содержимое пакета ассетов

Все ассеты представлены в двух форматах:
- **Векторный SVG** (`.svg`): идеальная четкость при любых разрешениях экрана и масштабах интерфейса.
- **Растровый PNG** (`.png`): отрендеренные с прозрачным фоном изображения для прямого вывода в Canvas/WebGL или быстрых спрайтов.

### 1. Ресурсы (`res_*.svg / .png`)
- `res_essence`: Пурпурный сияющий кластер кристаллов эссенции.
- `res_wood`: Связка готических брёвен с железными обручами, мхом и каплями смолы.
- `res_supply`: Лимит населения — рыцарский шлем с золотым нимбом и паутинным орнаментом.
- `res_silk`: Сферический кокон из плотной паутины с янтарной сердцевиной (Фото 2).
- `res_meat`: Свежий мраморный ломоть мяса / добыча (Фото 2).
- `res_crystals`: Острые темные обсидиановые кристаллы с фиолетовой дымкой (Фото 2).

### 2. Командная панель и способности (`cmd_*.svg / .png`)
- `cmd_attack`: Атака / атакующий марш (скрещенный палаш и секира в боевом пламени).
- `cmd_stop`: Стоп / удержание позиции (кованый щит с золотой звездой).
- `cmd_return`: Сдать груз (обоз с ресурсами и стрелка возврата).
- `cmd_cancel`: Отмена приказа (красная сургучная печать с ярким крестом).
- `cmd_rally`: Точка сбора (золотой штандарт с кругами призыва).

### 3. Здания фракций (`bld_*.svg / .png`)
**Орден Последнего Света (Люди):**
- `bld_citadel`: Главная Цитадель с башнями, витражом и золотыми знаменами.
- `bld_barracks`: Казармы — каменная крепость со скрещенным оружием.
- `bld_chapel`: Часовня — соборный шпиль с сияющим крестом и витражным окном.
- `bld_tower`: Сторожевая башня со стрелковыми бойницами.

**Древняя Колония (Пауки по Фото 2):**
- `bld_nest`: Главное гнездо (органический курган с янтарным свечением).
- `bld_incubator`: Инкубатор (кокон-хризалида на паучьих лапах).
- `bld_workshop`: Шелковая мастерская (паутинный шатер с подвесными лампами).
- `bld_webtower`: Паутинная башня (готическая спираль в коконе).
- `bld_barricade`: Паутинное заграждение (частокол из кольев, оплетенный паутиной).

### 4. Юниты и Портреты (`unit_*.svg / .png`)
- `unit_novice`: **Послушник (Рабочий)** — монах в капюшоне со строительным молотом. *(Заполняет пробел — ранее в игре у рабочего не было арта!)*
- `unit_swordsman`: Мечник в бацинете со стальным палашом.
- `unit_crossbowman`: Арбалетчик в саллете с тяжелым арбалетом.
- `unit_knight`: Рыцарь в топфхельме с золотыми эполетами.
- `unit_priest`: Жрец в митре с солнечным посохом.
- `unit_hunter`: Охотник на чудовищ в кожаном клобуке.
- `unit_spider_scout`: Паук-разведчик с рубиновыми глазами.
- `unit_spider_fang`: Паук-клык с ядовитыми жвалами.
- `unit_spider_weaver`: Паук-ткач с коконом (Фото 2).
- `unit_spider_spitter`: Паук-плеватель с кислотным брюшком.
- `unit_spider_armored`: Панцирник с костяным налобником.

### 5. Иконки характеристик (`stat_*.svg`)
- `stat_hp`: Здоровье (рубиновое сердце).
- `stat_dmg`: Урон (скрещенные клинки).
- `stat_armor`: Броня (кованый щит).
- `stat_range`: Дальность боя (прицел).
- `stat_heal`: Лечение (изумрудный крест).
- `stat_cargo`: Переносимый груз (мешок / кокон).

### 6. Эмблемы и Гербы фракций (`crest_*.svg / .png`)
- `crest_humans`: Орден Последнего Света (Солнечный меч и сияние заката).
- `crest_spiders`: Древняя Колония (Восьмиконечная паутина и всевидящее око).

### 7. Рамки и Декоративные элементы (`frame_*.svg / ui_*.svg`)
- `frame_bottom_panel`: Нижняя монументальная консоль Warcraft III.
- `frame_minimap`: Резная каменная оправа миникарты с угловыми накладками.
- `frame_portrait`: Готическая стрельчатая арка портрета.
- `ui_healthbar`: Металлическая оправа шкалы здоровья с делениями.
