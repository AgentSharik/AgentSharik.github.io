# SILKFRONT — проверка контрольного этапа 01

## Подтверждено
- Генератор сохраняет 10 юнитов, по 29 кадров и 5 состояний.
- `npm run build`: 0 обрезанных кадров для каждого юнита.
- `node verify.js`: 71 пара PNG/SVG (70 ресурсов юнитов и линейка), 10 JSON-атласов, 290 кадров, 50 состояний.
- Единая ячейка 288×288, опора 144,228; направление +X.
- HTML содержит встроенные данные и JS, не использует fetch, модули или CDN.
- Браузерная проверка по HTTP: переход к странице Панцирника, отображение пяти состояний и spritesheet; последняя проверка без ошибок JS.

## Исправления этой проверки
- Контейнер карточки больше не растягивает страницу до ширины spritesheet.
- Время первого requestAnimationFrame ограничено снизу нулём: отрицательный dt мог дать отрицательный индекс кадра и остановить воспроизведение.
- Модели, риги, координаты и размеры не переработаны.

## Ограничения и художественная оценка
- Это процедурный концепт, не окончательно принятый игровой арт.
- Ракурс заявлен как 3/4 сверху; точное соответствие объёмной камере Warcraft III не подтверждено. Изображения выглядят довольно плоскими.
- Полная визуальная приёмка силуэтов всех десяти юнитов и выразительности всех пяти действий остаётся открытой.
- Прямой запуск file:// не проверен: доступный инструмент браузера допускает локальные HTTP-серверы. Статическая проверка автономности не заменяет этот тест.
- Для открытия без сервера: открыть ART/CATALOG/gallery.html двойным щелчком, сохранив рядом структуру ART и ART_SRC. HTML не является единственным переносимым файлом: изображения загружаются по относительным путям.
- Герои и здания не создавались. Дальнейшая художественная переработка — после оценки пользователя.
