# SILKFRONT — Визуальная система интерфейса (Полная рабочая сборка)

Данный архив содержит **полную обновлённую версию браузерной RTS SILKFRONT** с интегрированной новой двуфракционной дизайн-системой интерфейса (в эстетике мрачного готического фэнтези и ориентира качества Warcraft III), а также **автономный интерактивный HTML-прототип** со всеми экранами и синхронным стендом сравнения HUD обеих фракций рядом.

---

## 1. Быстрый запуск и проверка

### Вариант А — Автономный интерактивный прототип (без сервера, в 1 клик)
Если вы хотите сразу просмотреть все 7 экранов интерфейса, переключать темы фракций и сравнить HUD **Ордена Последнего Света** и **Древней Колонии** рядом без запуска локального сервера:
1. Распакуйте архив `SILKFRONT.zip` в любую папку.
2. Откройте файл **`SILKFRONT/SILKFRONT_UI_Prototype.html`** (или `SILKFRONT/GAME/ui-prototype.html`) двойным кликом в любом современном браузере (Chrome, Edge, Firefox, Safari).
3. Все 42 векторных SVG-ассета встроены внутрь этого файла, поэтому он работает напрямую через `file://`.

### Вариант Б — Запуск полноценной игры SILKFRONT с интегрированным новым интерфейсом
Для запуска живой RTS-игры с загрузкой 10 спрайтовых атласов юнитов из каталога `ART/`:
1. Убедитесь, что установлен **Node.js** (внешние npm-пакеты не требуются — сервер использует только встроенные модули Node.js).
2. Перейдите в папку игры:
   ```bash
   cd SILKFRONT/GAME
   ```
3. Запустите локальный сервер:
   ```bash
   npm start
   ```
   *(или `node serve.js 5180`)*
4. Откройте в браузере адрес, выведенный в консоль:
   `http://127.0.0.1:5180/GAME/index.html`
5. Для запуска 47 автоматических модульных и симуляционных тестов движка выполните:
   ```bash
   npm test
   ```

## 2. Архитектура визуальной системы: Единая структура — Две фракционные темы

Вся интерфейсная оболочка построена на единой сетке, единых размерах интерактивных областей и общей логике управления, но динамически переключается между двумя темами через атрибут `body[data-theme="HUMANS" | "SPIDERS"]`:

1. **Орден Последнего Света (`HUMANS`)**:
   - Светлый готический камень и соборный сланец (`#332c25`, `#221d18`).
   - Кованое серебро и червонное золото (`#e0b864`, `#fff0b8`, `#d6dce4`).
   - Багряные бархатные стяги (`#7a1c26`, `#b82a38`), рыцарская геральдика (`crest_humans.svg`) и готические стрельчатые арки.
   - Окно задач миссии оформлено как средневековый пергаментный военный журнал.
2. **Древняя Колония (`SPIDERS`)**:
   - Тёмный обсидиан и хитиновый панцирь (`#2b1d3d`, `#1b1228`, `#0e0916`).
   - Органические переплетения паутины, фиолетово-багровые (`#3d2550`, `#9e2a6b`) и холодные бирюзовые биолюминесцентные акценты (`#47c3b4`, `#c2fff6`).
   - Паучья символика (`crest_spiders.svg`) и биомеханические контуры.
   - Окно задач миссии оформлено как резная хитиново-шёлковая скрижаль.

## 3. Структура созданных и обновлённых файлов

- `SILKFRONT/SILKFRONT_UI_Prototype.html` — самостоятельный однофайловый интерактивный стенд всех 7 экранов и сравнения HUD обеих фракций рядом.
- `SILKFRONT/GAME/ui-prototype.html` — копия интерактивного стенда внутри каталога `GAME/` (доступна по кнопке «★ Интерактивный стенд UI» прямо из главного меню игры).
- `SILKFRONT/GAME/index.html` — обновлённая разметка игры (верхняя статусная панель `#top`, нижняя консоль `#panel`, многоэкранное главное меню `#menu`, военный журнал `#mission-objectives`, диалоги брифинга и подтверждения сдачи).
- `SILKFRONT/GAME/style.css` — полная таблица стилей двуфракционной дизайн-системы с адаптивным масштабированием (`1440×960`, `1024×768`, `720×640`, `4K`) и точным соблюдением геометрии игрового поля (`#view` `top: 32px`).
- `SILKFRONT/GAME/src/hud.js` — обновлённый контроллер HUD с иконками приказов, зданий и юнитов (`UI_ICONS`), портретами для всех типов объектов (включая рабочего `human_novice` и все здания), шкалой здоровья и бейджами характеристик.
- `SILKFRONT/GAME/src/ui-system.js` — новый модуль управления фракционными темами, экранными вкладками меню (Кампании, Миссии, Фракции и Герои, Сравнение HUD рядом) и кастомными всплывающими подсказками (`#sf-tooltip`).
- `SILKFRONT/GAME/src/game.js` — подключение `initUiSystem(this)` и автоматическое переключение темы при старте матча за выбранную фракцию.
- `SILKFRONT/GAME/assets/ui/` — полный каталог из **115 файлов** графических ресурсов интерфейса (42 векторных `.svg` + 42 растровых `.png` + `MANIFEST.json`, `README.md`, `gallery.html`).
